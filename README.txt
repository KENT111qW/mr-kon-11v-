============================================================
 БОТ "11В. Мистер Кон Ча Янь" — учитель информатики
============================================================
Язык: русский. Для учеников 4-11 классов.
Работает через бесплатную нейросеть Google Gemini (gemini-1.5-flash).

------------------------------------------------------------
ШАГ 1. Получить токен Telegram-бота (бесплатно)
------------------------------------------------------------
1. Открой Telegram и найди бота @BotFather
2. Напиши ему команду:  /newbot
3. Придумай название: например  11В. Мистер Кон Ча Янь
4. Придумай юзернейм, должен заканчиваться на bot, например: mr_kon_cha_yan_11v_bot
5. BotFather выдаст токен вида  1234567890:AAHxxxx...  — скопируй его.
   Если потеряешь — /mybots -> выбери бота -> API Token

------------------------------------------------------------
ШАГ 2. Получить ключ Google Gemini (бесплатно)
------------------------------------------------------------
1. Зайди на сайт: https://aistudio.google.com/app/apikey
2. Войди своим Google-аккаунтом
3. Нажми Create API key -> Create API key in new project (или выбери существующий проект)
4. Скопируй ключ. Бесплатный лимит — достаточно для школы.
   Документация: https://ai.google.dev/gemini-api/docs

------------------------------------------------------------
ШАГ 3. Настроить проект локально
------------------------------------------------------------
1. Скопируй файл .env.example в .env:
   - В проводнике скопируй .env.example -> переименуй в .env
   - Или командой:  copy .env.example .env

2. Открой .env в Блокноте и вставь свои ключи:
   TELEGRAM_TOKEN=твой_токен_от_BotFather
   GEMINI_API_KEY=твой_ключ_Gemini

3. Установи Python 3.10 или новее (https://www.python.org/downloads/)
   При установке поставь галочку Add python.exe to PATH

4. Открой командную строку (cmd) в папке G:\инф и выполни:
   pip install -r requirements.txt
   python bot.py

   Если все верно — увидишь: "Бот Мистер Кон Ча Янь запущен."
5. Открой Telegram, найди своего бота по юзернейму и напиши /start

------------------------------------------------------------
ШАГ 4. Деплой на Render.com бесплатно (чтобы бот работал 24/7)
------------------------------------------------------------
Вариант А — Background Worker (рекомендуется для бота):

1. Зарегистрируйся на https://render.com (можно через GitHub)
2. Залей проект на GitHub:
   - Создай репозиторий на github.com
   - В папке G:\инф выполни:
     git init
     git add bot.py requirements.txt .gitignore README.txt .env.example
     git commit -m "Бот Мистер Кон Ча Янь"
     git branch -M main
     git remote add origin https://github.com/ТВОЙ_ЛОГИН/ТВОЙ_РЕПОЗИТОРИЙ.git
     git push -u origin main
   Внимание: .env НЕ отправляется (он в .gitignore) — это правильно.

3. В Render нажми New + -> Background Worker -> выбери свой GitHub-репозиторий
4. Настройки:
   Name: mr-kon-cha-yan-11v
   Runtime: Python 3
   Build Command:  pip install -r requirements.txt
   Start Command:  python bot.py
5. В разделе Environment добавь две переменные:
   TELEGRAM_TOKEN = твой токен
   GEMINI_API_KEY = твой ключ Gemini
6. Нажми Create Background Worker — бот запустится через 1-2 минуты.
   Логи смотри во вкладке Logs.

Вариант Б — если Background Worker недоступен на бесплатном тарифе:
  Используй тип Web Service с тем же Build/Start Command.
  Бесплатный Web Service засыпает без запросов, но для polling-бота
  лучше именно Background Worker (на момент 2024-2025 он бесплатен).

------------------------------------------------------------
ЕСЛИ ЧТО-ТО НЕ РАБОТАЕТ
------------------------------------------------------------
- "TELEGRAM_TOKEN не задан" — проверь файл .env, нет ли пробелов/кавычек
- "GEMINI_API_KEY не настроен" — проверь ключ на aistudio.google.com
- Бот не отвечает — смотри логи в консоли или в Render -> Logs
- Ошибка 401 Unauthorized — неверный TELEGRAM_TOKEN, пересоздай у @BotFather
